# 基于CNN的芯片表面缺陷智能检测系统


## 📌 项目简介

本项目是一个面向半导体芯片制造场景的缺陷智能检测系统。利用卷积神经网络（CNN）对芯片表面缺陷图片进行分类，识别出4种常见缺陷类型，实现芯片表面缺陷的自动识别与分类。

**关键词**：深度学习、CNN、芯片缺陷检测、工业视觉、PyTorch

## 📊 数据集说明

本数据集为**半导体芯片表面缺陷检测数据集**，来自真实芯片制造产线。

### 数据集规模

| 数据集 | 图片数量 | 说明 |
|:---|:---:|:---|
| 训练集 (train) | — | 用于模型核心训练 |
| 验证集 (val) | — | 用于调优超参数 |
| 测试集 (test) | — | 用于最终评估 |
| **总计** | **2500张** | 高质量半导体芯片图像 |

### 缺陷类别（4类）

| 类别编号 | 缺陷名称 | 缺陷说明 |
|:---:|:---|:---|
| 0 | ZF-scratch | ZF系列芯片特有的表面划痕（制程工艺相关） |
| 1 | scratch | 芯片通用型表面划痕（切割、封装环节产生） |
| 2 | broken | 芯片边缘/表面破损（封装或运输物理损伤） |
| 3 | pinbreak | 芯片引脚断裂/引脚变形（焊接或插拔导致） |

### 数据格式

- **原始格式**：YOLO目标检测格式（images/ + labels/）
- **转换后格式**：分类格式（按类别分文件夹）
- **标注精度**：像素级，缺陷定位准确率 ≥ 99%
