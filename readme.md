## 📌 项目简介

本项目是一个面向半导体芯片制造场景的缺陷智能检测系统。基于卷积神经网络（CNN）对芯片表面缺陷图片进行分类，识别出4种常见缺陷类型，并构建了完整的 Web 应用，支持图片上传、实时预测、错误样本收集与模型优化。

**关键词**：深度学习、CNN、芯片缺陷检测、工业视觉、PyTorch、Flask

## 📊 数据集说明

本数据集为**半导体芯片表面缺陷检测数据集**，来自真实芯片制造产线，聚焦芯片制造环节的外观缺陷识别。

### 数据集规模

| 数据集 | 图片数量 | 说明 |
|:---|:---:|:---|
| 训练集 (train) | ~2136张 | 用于模型核心训练 |
| 验证集 (val) | ~133张 | 用于调优超参数 |
| 测试集 (test) | ~135张 | 用于客观评估 |
| **总计** | **~2404张** | 高质量芯片图像 |

### 缺陷类别（4类）

| 类别编号 | 英文名称 | 中文名称 | 说明 |
|:---:|:---|:---|:---|
| 0 | ZF-scratch | ZF划痕 | ZF系列芯片特有的表面划痕（制程工艺相关） |
| 1 | broken | 破损 | 芯片边缘/表面破损（封装或运输物理损伤） |
| 2 | pinbreak | 引脚断裂 | 芯片引脚断裂/引脚变形（焊接或插拔导致） |
| 3 | scratch | 划痕 | 芯片通用型表面划痕（切割、封装环节产生） |

## 🚀 核心功能

### 1. 智能检测
- 支持单张/多张图片上传（拖拽或点击选择）
- 实时显示预测结果（类别 + 置信度 + 各类概率分布）
- 检测完成后自动汇总统计（总数、成功、失败、各类别数量）

### 2. 错误样本管理
- 检测结果卡片中直接选择真实类别并标记为错误
- 错误样本自动存入错误样本库（按预测类别分类）
- 同一图片多次报告自动去重合并，显示报告次数
- 点击报告次数查看完整历史记录

### 3. 一键模型切换
- 原始模型 ↔ 优化模型 实时切换
- 切换后自动清空检测区域，避免混淆
- 无需重启服务

### 4. 识别历史
- 按日期范围筛选历史记录
- 点击记录查看预测详情（各类概率分布）
- 支持清空历史记录

### 5. 模型优化微调
- 从数据库读取已标记真实类别的错误样本
- 混合训练策略（原始训练集 + 30%错误样本），防止过拟合
- 每次优化保存独立版本（带时间戳）
- 记录版本元信息（时间、验证准确率、样本数）
